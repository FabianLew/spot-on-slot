# W8 search screens: implementation plan

Spec: `docs/superpowers/specs/2026-10-06-w8-search-design.md`.

## Approach

`/search` is one client screen (`components/search/search-screen.tsx`) whose whole state lives in the URL
(`search-params.ts`: parse, serialize, and turn into API queries; Warsaw time via `warsaw-time.ts`, zł -> grosze).
The default centre comes from the account: an artist's own location (`GET /locations/me`), a venue account's first
venue with a point (venue accounts usually have no personal location), else nothing ("pick a place"). The screen
always sends `lat`/`lng`, since the map needs the centre anyway.

Results: the list uses `useInfiniteQuery` (20 per page, "Pokaż więcej"), the map one query of the 100 nearest; both
cancel through TanStack's `signal`. The map (`search-map.tsx`, MapLibre, HTML markers grouped by identical point,
popups with links) is loaded with `next/dynamic` and `ssr: false`; tests swap it for a fake.

Moving the map: `map-move.ts` holds the pure parts (radius from the view = centre to corner, capped 1–200 km;
"is this move worth a search" = zoom changed or centre moved more than a quarter of the view; an idle trigger that
fires 0.8 s after the last `moveend` and is cancelled by `movestart`). Only user moves count; flying to a picked
place does not. With "Szukaj przy przesuwaniu mapy" (per-viewer, `localStorage`, default on) a settled move writes
the map centre and radius into the URL as "Obszar mapy"; with it off a "Szukaj w tym obszarze" button does.

## Steps

1. Tests first: `search-params.test.ts`, `map-move.test.ts`, `search.test.tsx` (screen with a fake map).
2. `search-params.ts`, `map-move.ts`, `queries.ts`, `use-search-center.ts`.
3. Screen, filters (inline on desktop, `Sheet` on phones), result cards, list/map switch.
4. `search-map.tsx` + style (OpenFreeMap positron/dark, `NEXT_PUBLIC_MAP_STYLE_URL` overrides), pixel pins.
5. `search.*` messages PL/EN, page `app/(app)/search/page.tsx`, CLAUDE.md bullet.
6. `pnpm lint && pnpm typecheck && pnpm test && pnpm build`, e2e against the real backend with a stubbed tile
   style (the sandbox cannot reach the tile server), screenshots to `w8-screens/`, PR.
