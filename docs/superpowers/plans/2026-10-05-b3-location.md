# B3 location: implementation plan

Spec: `docs/superpowers/specs/2026-10-05-b3-location-design.md` (approved 2026-10-05).

**Ground rules:** test first per task; backend tests need Docker; `./gradlew test` in `apps/backend`; after API changes `pnpm api:generate` and commit `schema.d.ts`; before push `pnpm lint && pnpm typecheck && pnpm test && pnpm build`.

## Backend (`pl.spotonslot.location`)

1. **Shared 503.** `ServiceUnavailableException` in `shared.error` and a generic `SERVICE_UNAVAILABLE` code with PL/EN texts, so an unavailable dependency gets a 503 problem instead of a 500.
2. **Geocoder.** `Geocoder` interface (`search(query, locale)`, `reverse(point, locale)`) and `PhotonGeocoder` on `RestClient`. Properties: `spotonslot.location.*` with `geocoder-url`, `user-agent`, timeouts, suggestion limit and bias point. Photon `lang=default` for PL and `en` for EN. Results are mapped to `Place` (label, city, region, country code, point), with the "województwo" prefix trimmed. Any I/O or HTTP failure becomes `LOCATION_GEOCODER_UNAVAILABLE`. Unit test against `MockRestServiceServer`.
3. **Migration + domain.**
   - `V5__location.sql`: `location` with `subject_type` + `subject_id` (unique), `source`, `precision`, label, city, region, country code, latitude and longitude.
   - A generated, stored `geography(Point, 4326)` column with a GIST index.
   - `Location` entity; `GeoPoint.approximate()` rounds to a 0.01° grid.
   - `LocationErrors`.
4. **Service + API.**
   - `LocationService`: `search`, `setForUser` (approximate, reverse geocode, upsert, unique violation → 409), `getForUser`, `deleteForUser`.
   - `LocationController`: `GET /api/v1/locations/search?q=` (3–100 chars), `PUT|GET|DELETE /api/v1/locations/me`.
   - Facade `Locations.findWithin(SubjectType, GeoPoint, radiusKm, limit)` in the module root, with a native `ST_DWithin` query sorted by distance; radius 1–500 km.
5. **Integration tests.**
   - Photon stub: JDK `HttpServer` registered in `TestcontainersConfiguration`, so every test shares one context.
   - Cases: device and manual save, approximation, overwrite, read, delete, not set, geocoder down, no city, validation, search, radius query (distances, order, type filter, limits).
   - `ModularityTest` must stay green.
   - Prod requires `LOCATION_GEOCODER_URL`.

## Web

6. **ui:** `LocationPicker` (combobox with suggestions and keyboard support, "use my location" button, loading state, error with icon), text via props. Tests.
7. **web:** `/design/location` preview page (signed in): debounced search, device location through `navigator.geolocation` (a denied permission shows a hint to type the city), shows the saved location and lets you delete it. Copy PL/EN, test with mocked `fetch`.
8. **Docs and PR.**
   - Docs: `CLAUDE.md`, and the env table in `docs/architecture.md`.
   - End-to-end check with the backend, a stub Photon and web (geolocation emulated).
