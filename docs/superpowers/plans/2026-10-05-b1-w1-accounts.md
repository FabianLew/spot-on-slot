# B1 + W1 accounts: implementation plan

Spec: `docs/superpowers/specs/2026-10-05-b1-w1-accounts-design.md` (approved 2026-10-05).

**Ground rules:** test first per task; backend tests need Docker (`dockerd &`), run `./gradlew test` in `apps/backend`; after API changes `pnpm api:generate` and commit `schema.d.ts`; before push `pnpm lint && pnpm typecheck && pnpm test && pnpm build`.

## Backend (`pl.spotonslot.identity`)

1. **Migration + domain.** `V3__identity.sql`: `identity_user` (unique `email`), `identity_token`, `identity_refresh_token` (unique `token_hash`, index on `family_id`). Entities `UserAccount`, `OneTimeToken`, `RefreshToken`, enums `Role` (ARTIST, VENUE, BOOKER, ADMIN), `AccountStatus`, `TokenType`; `SecretToken` (generate + SHA-256, same scheme as waitlist). Unit tests for the entities' rules.
2. **Properties + JWT.** `IdentityProperties` (`spotonslot.identity.*`: access TTL 15m, refresh TTL 30d, verification TTL 48h, reset TTL 1h, resend interval 10m, pending retention 7d, `jwt-secret`, `jwt-issuer`, `cookie-secure`), `JwtService` with Nimbus `JwtEncoder`/`JwtDecoder` (HS256). Prod requires `JWT_SECRET` (≥ 32 bytes, startup fails otherwise). Add `spring-boot-starter-oauth2-resource-server`.
3. **Security wiring.** `SecurityConfig` gets `oauth2ResourceServer().jwt()` with the identity decoder and a `role` → `ROLE_*` converter; `/api/v1/auth/**` public. A shared `AuthenticatedUser` principal accessor stays in `identity`'s root package.
4. **Registration + verification.** `AccountService.register/verify/resendVerification`; events `EmailVerificationRequested`, `AccountAlreadyExists`, `UserRegistered`. Identical 202 for new/existing e-mail (and for the unique-key race). Integration tests.
5. **Login, refresh, logout.** `SessionService`: credentials check (same error for unknown e-mail / wrong password; pending → `IDENTITY_EMAIL_NOT_VERIFIED`; blocked → `IDENTITY_ACCOUNT_BLOCKED`), refresh rotation with family revocation on reuse, logout. Cookie `sos_refresh` (`HttpOnly`, `SameSite=Lax`, `Path=/api/v1/auth`, `Secure` from properties). Integration tests incl. reuse detection and expiry via a mutable test `Clock`.
6. **Password reset + `/me`.** `PasswordResetRequested` event, confirm revokes all refresh tokens. `GET /api/v1/me`.
7. **Cleanup job** for pending accounts older than 7 days.
8. **Notification mails.** `AccountMailer` in `notification` for the three identity events (PL/EN texts in `messages_*.properties`), links from `spotonslot.web.base-url` (`WEB_BASE_URL`, required in prod). Integration test with a captured `JavaMailSender`.
9. Error texts PL/EN, `ModularityTest` green, OpenAPI regenerated.

## Web

10. **api-client.** Session-aware client: `createApiClient({ getAccessToken, onUnauthorized })` middleware adds `Authorization`, on 401 runs one shared refresh and retries once; `credentials: "include"` for `/api/v1/auth/*`. Tests with a mocked `fetch`.
11. **Session in web.** `SessionProvider` (access token in memory, `refresh()` on start, `/me`, `logout()`), `AuthGate` in `(app)/layout.tsx` (loading screen, redirect to `/login?next=`). Tests.
12. **Screens** in a new `(auth)` route group with the arcade style: `/register` (role step = the mockup's role select, moved from `/design/role`; form step), `/check-email`, `/verify-email`, `/login`, `/forgot-password`, `/reset-password`. zod schemas with `validation.*` keys, `applyServerErrors`. PL/EN copy under `auth.*`. Tests per form.
13. **Logout** in the user menu and the "Więcej" sheet.
14. Verify end to end locally (backend + Mailpit + web), screenshots to `/mnt/project-files/b1-w1-screens/`, PR.
