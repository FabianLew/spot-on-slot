# W12 dashboard: implementation plan

Spec: `docs/superpowers/specs/2026-10-08-w12-dashboard-design.md`. Frontend only; every number comes from endpoints that already exist.

## Data

- **Bookings**
  - `useDashboardBookings(scope, venueId)` runs `GET /api/v1/bookings` with `size=3` for `awaiting` and `upcoming`.
  - It returns `{ bookings, total }`. The total feeds the "Czeka na mnie" tile.
  - Keys sit under `["bookings", "dashboard"]`, so booking writes invalidate them, and they refetch every minute.
- **Tonight**
  - These are the upcoming bookings that start today in Warsaw or have already started (an accepted booking that ended reads as COMPLETED).
  - They are taken from the same `upcoming` query, which is sorted soonest first.
- **Unread**
  - An artist, or a venue account with one venue: `useUnreadConversations` (exact count).
  - With several venues, the tile counts conversations with `unreadCount > 0` on the first list page of the chosen venue, because `unread-count` has no `venueId`. The list comes from `useConversations(venueId)`; the section shows the first 3 unread.
- **Free time (artist)**
  - `useCalendar(now, now + 60 days)`, then `nextFree(…, 3)`.
  - "Ogłoszony" comes from `announcing(useArtistListings("active"))`.
- **Venue listings**
  - `useVenueListings(venueId, "active")`, sorted by `startsAt` with the first 3 shown.
- **Artists nearby**
  - `GET /api/v1/search/artists` with the venue's point, `radiusKm=50`, `size=1`, using `totalElements`.
  - The query is skipped when the venue has no point.

## Components (`apps/web/src/components/dashboard`)

- `dashboard-screen.tsx` (`"use client"`):
  - `DashboardScreen({ venueId })` picks `ArtistDashboard`, `VenueDashboard` or a greeting.
  - Shared pieces: `Section` (title, "Wszystkie" link, empty text with a button, `ApiErrorState` per section), `BookingRow`, `ConversationRow`, `Tonight`, `QuickActions`.
- `queries.ts`: the hooks above.
- `dashboard.test.tsx` covers:
  - both roles on sample data;
  - empty states;
  - tonight only on the gig day;
  - the venue switch changing queries;
  - one failing section;
  - the reminder.
