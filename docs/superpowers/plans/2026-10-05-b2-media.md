# B2 media: implementation plan

Spec: `docs/superpowers/specs/2026-10-05-b2-media-design.md` (approved 2026-10-05).

**Ground rules:** test first per task; backend tests need Docker; `./gradlew test` in `apps/backend`; after API changes `pnpm api:generate` and commit `schema.d.ts`; before push `pnpm lint && pnpm typecheck && pnpm test && pnpm build`.

## Backend (`pl.spotonslot.media`)

1. **Dependencies + storage.** AWS SDK v2 `s3` (BOM), Thumbnailator, TwelveMonkeys `imageio-jpeg`, `webp-imageio`. `MediaProperties` (`spotonslot.media.*`: `endpoint`, optional `presign-endpoint`, `region`, `bucket`, `access-key`, `secret-key`, `public-base-url`, `max-bytes` 10 MB, `max-pixels` 40 MP, `upload-ttl` 10 min, `pending-retention` 24 h, `quota` 200). `S3Client` + `S3Presigner` beans (path-style). S3Mock (`adobe/s3mock:5.2.3`, initial bucket) in `docker-compose.yml` and in `TestcontainersConfiguration` via `@DynamicPropertySource`-style registrar.
2. **Migration + domain.** `V4__media.sql`: `media_upload` (owner, object key, content type, size, expires_at), `media` (owner, width, height, variant keys). Entities `MediaUpload`, `Media`; `MediaErrors` with the spec codes.
3. **Image processing.** `ImageProcessor`: type by magic bytes (JPEG/PNG/WebP), dimension check before decoding, EXIF orientation, three WebP variants (320/800/1600 longest side, never upscaled), no metadata in output. Unit tests with generated images (rotated EXIF JPEG, PNG with alpha, fake JPEG, oversize).
4. **Service + API.** `MediaService`: `createUpload` (quota, type/size validation, presigned PUT), `complete` (owner check, head + size check, process, put variants, delete original + upload row), `get`, `delete` (owner only), `deleteStaleUploads`. `MediaController` under `/api/v1/media`. `MediaCleanupJob` daily. Error texts PL/EN.
5. **Integration tests** against S3Mock: full flow, wrong type, too large, missing file, foreign upload, expired upload, delete, quota, cleanup. `ModularityTest` green. Prod env vars required in `application-prod.yml`.

## Web

6. **api-client:** `uploadImage(client, file)` runs the three steps; PUT failures become `ApiProblemError` with code `MEDIA_UPLOAD_FAILED`. Tests with mocked `fetch`.
7. **ui:** `ImagePicker` (button + drag and drop, preview, uploading state, error with icon), text via props. Tests.
8. **web:** `/design/upload` preview page (signed in) that uploads, shows the three variants and deletes. Copy PL/EN.
9. Docs (`CLAUDE.md`, `docs/architecture.md` env table, compose), end-to-end check with backend + S3Mock + web, screenshots to `/mnt/project-files/b2-screens/`, PR.
